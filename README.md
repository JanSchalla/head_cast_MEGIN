# head_cast_MEGIN

This workflow provides a detailed description of the workflow to create individualized head casts from an T1/T2 MRI scan for the Elekta/MEGIN NeuroMag MEG device. 

High level overview of the applied process:
1. Exctract and export headshape from MR using fieldtrip to a columetric .stl file.
2. Digitally place head into the NeuroMag dewar and add support structures.
3. Prepare 3D printing of the head.
4. Use self printed mold to create head casts.
